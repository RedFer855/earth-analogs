Challenge · Identify Earth locations that analog Moon and Mars base sites

Earth analogs of the places where we will live next.

We compare every 2.5 km cell of the planet against the candidate permanent Moon base regions and Mars sites, using several physical variables at once — slope, roughness, temperature, thermal inertia, mineralogy, permafrost, ice, wind, dust — and we state for each candidate what matches and what differs, gravity, atmosphere and pressure included.

Open the 3D viewer →

The viewer is a 3D globe served from your own machine, not a hosted page. node scripts/iniciar.mjs prints the port it picked (5173 unless it is taken); type it in the box and the button opens it.

Engine · Rust

Mahalanobis distance with a tolerance zone turned into a similarity score, one score per variable, and a sweep over 58,700,374 cells in 0.25 s on 16 threads. The same core compiles to WebAssembly for the browser.

Viewer · CesiumJS

3D globe with the documented analogs, the sweep candidates, cave and crater layers, and a sheet per area saying which variables agree and which do not, with a confidence level.

Data · open

NASA, USGS, ESA and other public archives, each product with its version, link and license. The 23 GB table is rebuilt with the ETL in the repository; it is never committed.

Run it on your machine

Requirements: Node.js 24 and nothing else. No Rust, no Python, no account, no API key.

git clone https://github.com/RedFer855/earth-analogs.git
cd earth-analogs
node scripts/iniciar.mjs
  • The script installs the viewer dependencies, starts the local bridge on 5174 and the viewer on the first free port, then opens the page.
  • node scripts/iniciar.mjs --run /path/to/run turns on the button that re-runs the Rust engine with another profile.
  • Without the 23 GB table the viewer still works: it shows the published results and the layers.
